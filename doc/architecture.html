IR · Intelligent Router — Architecture

智能路由 · 架构总览

IR Mesh：Core（控制面）与 Edge（执行节点）经 IR Link 组成的分布式智能体网络。 任务从任意入口进入 Core，由租约队列路由到某台 Edge 的机群执行，全程审计。

§0术语体系（IR 家族）

命名沿网络设备隐喻：Core/Edge/Link/Mesh 均为真实网络概念；全部术语以本表为单一事实源。

IR智能路由 · 伞形品牌整个产品：Core + 全部 Edge + Link 协议 + 业务层的总称。
IR Core核心路由器 · 控制面平台服务端（仓库 agent-server-go）：入口、路由决策、租约队列、审计、管理台。
IR Edge边缘路由器 · 执行节点机器端程序 ir：常驻 daemon 认领任务，派发给本机 Agent 执行。
IR Mesh智能体组网Core + 全部 Edge 构成的分布式网络；「管理运行中的智能体网络」即指此。
IR Link链路协议agent-api/v1：claim 长轮询 / renew 续租 / complete 幂等回执 / heartbeat 存活 / runs 直提。
ir-noded节点守护进程Edge 的服务形态（systemd/launchd 常驻）。
Node Console节点控制台Edge 本机 Web（127.0.0.1:7800）：配置与查看本机 Agent。
Central Console中央控制台Core 管理台 SPA：全局智能体、连接器、日志、团队编排。
Node Key / Cluster Key节点密钥 / 集群子密钥主密钥（入站签名 + 连接认证）与 HMAC 派生（按集群吊销）。
Fleet机群一台 Edge 上的执行池：本机 Agent 的集合与并发容量。
Run运行一次任务执行的全生命周期记录（审计主键）。
Position / Team岗位 / 编排业务层：职能模板与多步团队流程（Core 管理）。

§1IR Mesh 全局拓扑

左侧为任务入口，中部 IR Core 控制面，右侧为执行节点（每台机器一个 ir daemon + 一个 Fleet）。 Core 与 Edge 之间唯一通道是 IR Link（出站长轮询，Edge 无需公网入口），认证由 Node Key / Cluster Key 完成。

§2IR Core 内部分层（DDD）

依赖方向自上而下单向：api → app → domain ← infra。架构守护测试（archguard）在 CI 中强制这些边界。

§3IR Edge 内部（ir 单二进制）

三种形态一体：CLI 子命令、常驻 daemon（ir-noded）、本机 Web 控制台。daemon 与平台之间只经 agentapiclient（IR Link HTTP 客户端），本仓库不 import 平台任何内部包。

§4任务生命周期（租约状态机）

交付语义为 at-least-once：租约过期即重派（attempts ≤ MAX_ATTEMPTS），双执行风险由 claim 携带 attempts 与审计可追溯来管理；有副作用的连接器须自行幂等。三级时限：队列 TTL → 单次租约 → 执行墙钟。

§5安全模型（三种凭据）

动态入口的入站签名走各智能体的 Node Key；Edge 连接认证共享同一把主密钥或其派生子密钥； act_ 连接器令牌为兼容路径（管理台签发，可服务多智能体）。

Node Key节点密钥（主密钥）智能体签名密钥。入站：调用方以 HMAC 签名请求动态入口；连接：Edge 直接 Bearer 持有（持主密钥者视为可信，不受集群名单影响）。轮换有 24h 宽限。
Cluster Key集群子密钥base64url(HMAC-SHA256(NodeKey, "ir-cluster-v1\0" + clusterID))。平台按名单验算——名单删除即吊销该集群，主密钥与其余集群不受影响。推荐多集群部署形态。
act_ Token连接器令牌（兼容）Central Console 签发，SHA-256 落库、明文一次性展示；scope 限定可认领的 slug 集合；轮换带宽限期。
运行时防线纵深防御入队/认领/回执全程 Bearer；claim 403 防枚举；双实例 409 检测；attempts 与派发审计让双执行可追溯；密钥轮换宽限不中断在途任务。
